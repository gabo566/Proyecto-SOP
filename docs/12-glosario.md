# Glosario

Última actualización: 2026-11-02. Código: `main` @ `11f61c3` (= `origin/main`; árbol con `README.md` modificado, sin commit).

| Término | Significado en el proyecto |
| --- | --- |
| SOP | Procedimiento operativo estándar que guía el desensamble. |
| GB200 | Familia de nodo que identifica la SOP base. |
| MFG | Área de manufactura. |
| RWK | Área de retrabajo. |
| Intake | Pantalla inicial donde se eligen estación/SOP y se capturan PN/seriales. |
| Hoja/procedure | Sección de una SOP con título, rango y pasos. |
| Paso | Instrucción numerada que se marca en el checklist. |
| SOP run | Recorrido guiado por las hojas de una revisión. |
| Retrabajo | Trabajo que se reabre por un paso fallido y puede requerir evidencia/revisión. |
| Work item | Registro local de un trabajo iniciado, detenido, reanudado o cerrado. |
| Handoff | Entrega de un trabajo activo a otro operador autenticado localmente. |
| Evidencia | Foto JPG, PNG o WebP asociada a validación, pausa o retrabajo. |
| Source bounds | Coordenadas del texto extraído usadas para resaltar un paso en la hoja PDF. |
| PDF.js | Biblioteca local usada para extraer texto y dibujar hojas PDF. |
| IndexedDB | Almacenamiento del navegador para PDF, versiones y fotos. |
| localStorage | Almacenamiento del navegador para registros, trabajos, usuarios y auditoría. |
| Demo | Registro ilustrativo que se excluye por defecto de métricas operativas. |
| Rev. | Revisión de la SOP; cada registro conserva la revisión utilizada. |
| PN | Número de parte del nodo o componente. |
| TDR / SYS_ASSY | Códigos de estaciones MFG configuradas en el catálogo local. |
